配置流程

龙猫云的接入可以概括成「选套餐 → 拿到订阅 → 安装客户端 → 导入并连接」。下面按实际操作顺序写，方便对照页面后半的套餐与客户端模块。

  1. 确认需求并打开套餐区

    估算同时在线的设备数量、主要用途（浏览、协作或影音），再到本页套餐区域对照档位。不要把价格抄到笔记之外的地方——以下模块由系统注入，以免和结算页不一致。

  2. 完成订阅并复制链接

    在结算成功后的账户页复制订阅地址（通常是一串以 http 或专有协议开头的链接）。只保存在本地密码管理器或客户端里，不要发到公开群聊。

  3. 前往客户端下载

    打开本页「客户端」一节，按系统选择对应程序。龙猫云 VPN 使用通用机场订阅格式，导入后即可被主流客户端识别；具体安装包以该模块给出的链接为准。

  4. 导入订阅并命名配置

    在客户端中选择「从 URL 更新 / 添加订阅」，粘贴链接，给配置起一个可辨认的名字（例如「龙猫云-主力」）。首次更新可能需要数秒，完成后会出现节点列表。

  5. 选择节点并开启系统代理

    优先选延迟较低、用途匹配的线路；需要影音时再换标注对应地区的节点。开启客户端的系统代理或 TUN 模式后，用浏览器访问目标站点验证。若失败，先排除本地防火墙、系统时间错误和订阅未更新。

  6. 多设备同步

    同一订阅可在额度内导入多台设备。建议只在常用终端保留自动更新，减少同时拉取造成的冲突。更换套餐后，在客户端执行一次「更新订阅」即可同步新配额。

配置重点：订阅链接等同于钥匙，泄露后别人可以占用你的流量。轮换链接或重置订阅的入口一般在账户后台，不在本页公开。

常见问题

龙猫云是什么？和普通 VPN 有何不同？

龙猫云是以机场订阅分发节点的网络加速服务。你购买的是可更新的订阅链接，而不是单一服务器账号。客户端负责解析订阅、测速和切换线路，官网页面则集中提供套餐与下载入口。

第一次使用龙猫云，最短要做哪几步？

按本页配置流程：选定套餐并付款，复制订阅链接，在客户端模块下载对应程序，粘贴链接更新节点，最后开启代理访问目标网站。五步都完成后才算接入成功。

为什么连接后网页仍打不开？

依次检查：订阅是否已更新、系统代理或 TUN 是否真正开启、本机时间是否准确、防火墙是否拦截客户端。仍失败时换一条线路，或暂时关闭再开启客户端，排除旧 DNS 缓存。

可以在几台设备上同时使用？

同时在线台数由你购买的套餐决定，请直接查看上方套餐模块中的设备说明，不要以口头传言为准。超出额度时，较早的会话可能被踢出，需要先退出闲置设备。

订阅链接泄露了怎么办？

立刻在账户后台重置或重新生成订阅，旧链接会失效。然后在各设备客户端里替换为新链接并更新。日常不要把链接截图发到社交平台或群文件。

流量或套餐到期如何续用？

在账户中续费同一档位或升级更高档。到账后在客户端执行一次订阅更新，新的流量与有效期才会出现。未更新时，客户端可能仍显示旧配额。

龙猫云官网下载的客户端是否必须使用指定软件？

以本页客户端模块列出的程序为准。只要客户端支持通用订阅导入，通常即可使用。不要从论坛附件或网盘镜像安装，以免证书被替换。
